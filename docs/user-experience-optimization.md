# 用户体验与技术优化记录

本轮沿用现有基础组件、Web 模板、Agent 客户端模板及 Nothing 设计语言，优化从开始绘制到本地保存的完整操作流程。

## 已实现

| 用户场景 | 改动与结果 |
| --- | --- |
| 首次打开 | 默认基础模式；空画布提供三种模式入口、简短说明及绘图快捷键；恢复本地项目期间先显示读取状态，防止编辑被加载结果覆盖。 |
| 找组件和模板 | Web、Agent 优先展示场景模板；统一列表结构、分类、尺寸标注；支持忽略首尾空格、多关键词与“模板/模版”搜索，提供无结果和清空操作；各模式的搜索条件独立，记住上次打开的模式。 |
| 添加内容 | 三个组件库均可点击或通过键盘添加到当前视野；拖拽可指定位置；新模板避开已有内容，自动适应可见区域。底部工具栏继续提供自由绘图。 |
| 查看画布 | 展开侧栏占据布局空间，避免遮挡画布；提供“适应全部内容”和“适应选中内容”，分别支持 Shift+1、Shift+2；缩小时降低可见网格密度，保持原有吸附网格。 |
| 多页面与预览 | 每页分别保留本次会话中的撤销历史、平移与缩放；重开项目时自动适应已有内容；预览往返保留视野，预览期间禁用编辑快捷键及撤销、重做按钮。 |
| 连续编辑 | 修复 50 个历史快照达到上限后的索引问题；一次拖动只形成一次历史提交；复用没有变化的元素分支和历史快照，避免重复深复制完整画布。未对帧率或内存改善幅度作量化承诺。 |
| 快捷键 | 修复普通方向键抢占 Shift、Alt 组合键的问题；保留 macOS Command 与 Ctrl+Y 重做兼容；输入法组合输入期间不触发编辑快捷键。 |
| 自动保存 | 显示待保存、保存中、已保存、保存失败和重试操作；只有对应版本写入成功才清除未保存状态；序列化文件写入和设置合并，防止旧保存覆盖新保存。 |
| 文件安全 | 新建同名项目生成独立文件；自动保存沿用项目已绑定的路径；手动保存期间暂停新的自动保存任务，另存为使用选定路径时的最新内容。 |
| 浏览器恢复 | 等待 IndexedDB 事务完成后才确认成功，关闭数据库连接；迁移失败保留原 localStorage 副本；恢复时选择较新的备用保存；存储额度不足向编辑器返回失败。 |
| 关闭与反馈 | 增加客户端关闭和浏览器离开的未保存保护；普通操作消息改为底部状态栏，错误保持可见；去除工具栏模糊、阴影和普通按钮的红色悬停背景。 |

## 验证证据

- `pnpm test`：60 项通过，其中新增 16 项测试直接加载生产 TypeScript；涵盖连续 100 次编辑、分支撤销、不可变更新、模板适配、搜索、修饰键、保存回滚、备用存储、同名文件、写入顺序、另存为和取消关闭。
- `pnpm typecheck`：编辑器包与 Next.js 应用类型检查通过。
- `BLUEPEN_BUILD_DIR=.next/build-check NEXT_EXPORT=true pnpm --filter app exec next build --webpack`：静态生产构建通过。
- `cargo check --locked --manifest-path apps/app/src-tauri/Cargo.toml`：当前 macOS 环境下检查通过，包括客户端关闭所需的窗口能力配置。
- 浏览器交互：基础组件添加、跨页撤销/重做、搜索空状态、模式切换、Web 与 Agent 模板自动适配、深浅主题。
- 最终使用静态生产产物复测：已有 35 个图层恢复且全部在视野中；空页面 100% 与已有页面 18% 的缩放独立；键盘添加登录模板后共 45 个图层，打散后 44 个图层，撤销后恢复 45 个；预览往返的画布变换保持一致。
- 再次打开生产预览：45 个图层完整恢复，显示“已保存”，并保留 Web 模板模式与深色主题。

## 验证范围

客户端文件服务与关闭保护使用生产代码和模拟 Tauri API 进行回归，并通过 Rust/能力配置检查。系统文件对话框、实际原生窗口关闭、安装包启动及 Windows/Linux 平台未进行实机验证。本轮没有发布安装包。

画布视图和撤销历史按页面在本次会话中保留；重开项目后自动适应现有内容，撤销历史不写入项目文件。

开发预览曾因构建缓存缺失返回 500，最终改用当前静态生产产物验证。设置 `BLUEPEN_BUILD_DIR` 时，Next.js 静态导出写入该目录；默认桌面构建仍输出至 `apps/app/out`。

# Agent 对象编辑：实现与验证

2026-09-11。承接 `agent-experience-reassessment-2026-09-11.md`，用户已授权直接实施。

## 已实现

- 画布选区工具条、右键菜单、图层列表均可把对象添加到会话；支持单个组件、多选、组合和画布中的模板实例。按真实图层 ID 引用，生成后仍可在属性面板手工编辑。
- 组件库新增「用作 AI 参考」，输入区支持 `@` 搜索项目图层和组件库、切换修改对象/仅作参考、移除和定位引用。
- 参考图片支持选择、粘贴、拖入；限制类型、数量和尺寸，处理后随消息交给模型。草稿、引用和发送时的对象快照随本地会话保存。
- 模型通过结构化操作更新属性、在组合内新增、删除、移动节点。简单属性调整经校验直接应用；结构调整先预览、再确认。未指定属性保留，不替换原组件 ID。
- 检查选区范围、锁定及父组合锁定、过期快照、手工修改冲突、连接线引用、属性类型和尺寸。整批操作校验完成后作为一次编辑器历史提交。
- 使用真实组件渲染器提供新增方案缩略预览及修改前后对比。模板生成展开为原子组件组。
- 每次应用保存独立修改记录；撤销保留后续不相关属性修改，同一字段或结构冲突时拒绝覆盖。结果状态根据当前文档显示已应用、已撤销、已有后续修改、已删除等。嵌套组合中的对象可定位。
- 支持用户消息复制和编辑重发、重新生成回复，保留既有澄清、停止、错误重试、会话历史和恢复功能。编辑重发作为新一轮，已应用的画布内容保留。
- 接入 Streamdown 2.6.0，保留 Controller 与 coss 输入区。适配结论见 `agent-product-patterns-2026-09-11.md` 第 8 节。
- 保持 Nothing 设计系统；助手与属性面板可切换，窄窗口保留左侧导航，浮动工具栏可横向滚动。

## 浏览器验证

使用本地开发应用、真实 React 界面和 Responses SDK，连接 `packages/editor/tests/agent-fixture-server.mjs` 的本地测试响应服务；仅使用测试密钥。

1. 从组件库添加两个不同按钮，多选后添加到会话。发送一次请求，两个原节点的文案均变为「确认提交」，图层数量仍为 2。见 `../output/agent-implementation-2026-09-11/01-batch-edit-dark.png`。
2. 打开前后对比，实际组件展示原文案和新文案。独立撤销后两者恢复，结果卡显示「已撤销」。见 `../output/agent-implementation-2026-09-11/02-before-after.png`。
3. 将两个按钮组合，引用组合并要求新增按钮。先出现待确认卡片；预览后点击「应用修改」，组合中出现可编辑的新按钮。见 `../output/agent-implementation-2026-09-11/03-group-insert-preview.png`。
4. 输入 `@登录` 引用组件库模板，再添加 PNG 参考图和草稿。刷新后重新打开助手，两个引用和草稿均保留。
5. 浅色模式、900 × 820 窗口下，导航栏宽 48 px，组件抽屉收起，助手输入和引用可操作。见 `../output/agent-implementation-2026-09-11/04-references-light-narrow.png`。

收尾检查发现组合预览合并选区与修改记录时会重复传入同一根节点，触发 React 重复键警告。已对预览目标去重，并补入覆盖「同一组合重复引用及其子节点」的生产模块回归断言。

## 当前边界

- 本轮没有用真实模型评估设计质量，也没有启动 Tauri 安装包验证；原生网络与凭据实现保持现有机制。
- 一次修改限同一目标页面；其他页面可作为只读参考。跨页面或跨项目的错误目标会被拒绝。
- 结构操作中的新增/移动目标必须是已引用的现有组合。自动布局设置不在本轮可写字段内。
- 独立撤销在结构发生后续变化时采用保守拒绝，不自动合并复杂结构冲突；旧会话中没有独立修改记录的生成结果仍使用编辑器历史撤销。
- 无提交、推送或发布操作。

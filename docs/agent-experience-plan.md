# Agent 体验改造计划

依据：[体验调研](./agent-experience-research.md)。目标：把现有原型规划助手升级为可观察、可协作、可恢复的会话工作台。

## 本轮交付

1. 独立应用设置页：Base URL、API Key、默认模型、显式保存与连接测试；聊天中移除凭据表单。桌面 Key 使用系统凭据库，Web Key 默认仅本次浏览器会话保存；旧配置安全迁移。
2. 会话管理：直接打开助手，新建、切换、重命名、搜索、归档、删除、完整消息时间线、草稿与本地历史恢复。会话按稳定项目 ID 隔离；新建同名项目不共享历史。
3. 可观察运行：实际连接/工具执行/方案验证状态、可折叠的工具结果与模型提供的推理摘要、耗时、停止、失败重试；收起或切换会话不取消任务，停止后迟到事件不覆盖状态。
4. Ask human：结构化问题，选项与自由回答，必答校验、回答记录、继续原任务；与方案批准/拒绝分开。
5. 画布闭环：方案明确目标页面、版本、内容，确认前不写画布；重复确认不重复生成；成功保留会话与结果定位；切换页面/项目不误应用。保留现有画布撤销能力。
6. 体验与适配：Nothing 深浅主题、coss 原语、可调宽面板、消息自动滚动不抢阅读位置、输入法与键盘支持、存储失败可重试；桌面静态构建保持可用。

本轮仍以“讨论并生成可编辑原型”为能力边界。修改已有图层、任意外部工具、多 Agent 并发、语音和分支会话不属于本轮交付，不用 UI 暗示它们已可用。第一版只允许一个活动模型请求；重启恢复消息及待回答/待确认状态，已断开的运行明确标记中断。

## 实施顺序

1. 统一项目身份与存储格式兼容，建立独立 Agent 设置/凭据/会话存储。
2. 扩展现有 SDK 运行时与严格输出 schema，输出真实事件与结构化澄清问题；保留既有 Responses/TokenBox/Tauri 传输。
3. 建立可测试的会话控制器，隔离运行生命周期与面板显隐。
4. 构建设置页面、会话列表、时间线、问题与方案卡，接入编辑器入口、布局与画布结果。
5. 运行回归、类型检查、静态构建、Rust 检查；浏览器使用本地 Responses 测试服务走完整流程，不使用真实用户凭据。

## 验收清单

- [x] 设置保存/迁移成功后旧持久明文 Key 移除，失败不丢失；测试连接实际覆盖工具和结构化输出。
- [x] 新建/切换/重命名/搜索/归档/删除会话可用，重启保留历史与草稿。
- [x] 同名项目历史隔离，项目导出不含凭据或聊天内容。
- [x] 消息发送立即入列，正文流式更新，工具及推理来自实际事件。
- [x] 澄清必答校验、自由输入、提交记录、继续任务，重复提交不重复调用。
- [x] 方案确认/拒绝、应用去重、生成结果、画布定位、目标失效提示。
- [x] 收起/切换会话继续运行；停止/失败/中断可重试且旧回调无效。
- [x] 自动滚动、键盘操作、中文输入法、深浅主题、窄窗布局检查。
- [x] meaningful regression tests、类型检查、静态生产构建、Rust 检查完成；记录实测范围与限制。
